# D control: source preparation only

Status: NOT BUILT, NOT IMPORTED, NOT EXECUTED. This package does not authorize execution or timing. Root selects the failure policy and measurement scope, commissions independent review, freezes a concrete launcher/harness, and publishes. No product files changed.

## Mechanism and exact limits

`native_cf1.c` is a copy of F with `CF1_CONTEXT_CONTROL` selecting D at compile time. `SOURCE_DELTA.patch` is the exact delta against original F. Build the same copied source without this macro for its paired F control. Both use the identical copied `native_read.py`; that file is byte-identical to original F. Native module name and nine-argument ABI remain `native_cf1.open_encoded`; load each build in a separately pinned process, never a fallback import search. D's selected mode must be established from build command/source pins, not assumed from module name.

Each non-NULL D read derives a fresh payload key, fetches the cipher, allocates and keys a fresh encryption base, allocates and keys a fresh decryption base, allocates a fresh working context, copies the keyed decryption base into it, and supplies the frame nonce while retaining the copied key. The encrypt base really is keyed via EVP_EncryptInit_ex2. It is not used to encrypt dummy data. All three contexts are freed on success/refusal. No reusable state, cached key, capsule, global counter or alternate backend is introduced. Copy failure refuses immediately; no copy retry or reinitialization fallback exists.

This is not exact pyca construction: pinned pyca can recover a failed copy by fresh context/reinitialization, allocates output in a different order, uses its own packaging/backend, and has different allocator paths. D reserves its private output after working setup, exactly like F. D:F measures this wrapper's context strategy and associated cleanup only; no pyca constructor, backend-only, end-to-end or product claim follows.

Python preserves context admission, NULL active-payload resolution, frame validation, admitted payload then search resolution, strict UTF-8/NUL checks, and final payload then search resolutions before returning. Crypto order remains payload derivation, authenticated decrypt, then search derivation and constant-time full term check. No error-string cause inference. Unchanged private stage labels select unchanged safe wrapper classes: setup/AAD/new D sites -> CryptoBackendUnavailable; data/final -> AuthenticationFailed even for injected operational failures; term -> RepresentationMismatch. This is source-observable policy conditional on coordinator acceptance, not the stronger causal requirement. All existing allocation-order and salt-hash normalization limits remain.

Queue behavior is copied unchanged. This package does not claim arbitrary queue/mark preservation or provider-internal resource/zeroization proof.

## Ownership and cleanup map

- Python frame/scope/material arguments: borrowed immutable references held under GIL; never retained beyond call.
- Payload/search derive: owned fetched EVP_MD and EVP_KDF plus owned MD/KDF contexts, freed at derive's single cleanup on every exit; local salt/key intermediates cleansed as in F.
- Fetched cipher: owned once per call; freed after all direction/working contexts.
- D encrypt_base: NULL initially, ownership begins after selector36 allocation; freed exactly once if acquired, including key-init37 failure.
- D decrypt_base: NULL initially, ownership begins after selector38 allocation; freed exactly once if acquired, including key-init39 failure.
- Working cc: NULL initially, ownership begins after selector11 allocation; freed on copy40 failure, nonce12 failure, every later refusal and success. A failed copy may partially initialize destination; EVP_CIPHER_CTX_free is still applied. No fallback replaces or leaks it.
- Private result: new reference allocated at13; stays unexposed/zero-initialized until success; failure cleanses and decrefs, success transfers one reference.
- Scratch: allocated at14; clear-freed at cleanup on every later path. No plaintext returned before both authentication checks.
- HMAC and its context: owned and freed at common cleanup. Local keys, term, info, AAD cleansed. Provider internals, immutable Python roots/results and allocator copies are not proven erased.
- Diagnostic open_observed: call-local counters only; captures private exception type/value without traceback, packages them with value-or-None and counters, decrefs its temporary references. Packaging failure propagates; not converted into a success receipt. It is not a public API. Harness adapter must re-raise captured exception before the unchanged wrapper mapper. Observed failure must have value None. Normal builds contain neither this method nor counter storage/increments.
