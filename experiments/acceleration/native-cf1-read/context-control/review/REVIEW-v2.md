# Independent v2 diagnostic-preparation review

2026-10-14. Static review only of run_v2.py, build_v2.py, prepare_v2.py, freeze_v2.py, PLAN-v2.md, manifest-v2.json and FREEZE-v2.json. Original REVIEW.md remains unchanged. No candidate build/import/execution, network, PostgreSQL, provider changes or Git operations.

## Decision: HOLD on executable diagnostic admission

Two concrete pre-run gaps prevent unconditional diagnostic-only clearance:

1. **Executed Python cache provenance is not enforced.** run_v2 checks source hashes, find_spec origins and loaded __file__ strings, but normal imports can execute cached bytecode associated with those same source paths. FREEZE-v2 pins 606 files and zero .pyc files. Static filesystem inspection found 69 existing cryptography .pyc files (none under the D, original-F or S20-source directories at inspection time). The runner does not enforce a fresh isolated cache prefix, validate cache contents against source, or otherwise establish source-only loading. No stale cache was demonstrated or executed; this is a missing provenance guarantee, not a claim those caches are wrong. A concrete outer launch policy can close it by selecting/enforcing a fresh empty per-process cache prefix before imports, preventing cache writes if desired, and excluding startup/PYTHONPATH overrides. Merely adding -B would prevent writes, not cache reads.
2. **Run containment is a caller obligation, not an executable frozen launcher.** PLAN-v2 requires a 120-second caller timeout and preservation of stdout/stderr/exit code, but v2 supplies no outer launcher or exact launch receipt contract to enforce it. run_v2 itself has no timeout. The coordinator can close this with an explicitly frozen, reviewed outer command/process-containment policy before launch; no new crypto source changes are implied. Freeze both optimization modes, all six run modes per arm, expected terminal statuses, timeout/crash handling and exclusive output destinations. A timeout/crash must not count as a successful negative control. The build driver's 60-second compiler and 15-second dependency-inspection timeouts are explicit, but descendant containment should be included in the outer policy.

Additional source-stability gap: the final source/dependency pin check is reached only on positive completion. Each intended sensitivity failure exits inside retain(), before those final checks. Preserve final pins and a distinct integrity outcome for negative/error exits in a revised runner or outer launcher; otherwise an intended mismatch does not establish end-of-run source stability. Do not overwrite v2 evidence when revising.
