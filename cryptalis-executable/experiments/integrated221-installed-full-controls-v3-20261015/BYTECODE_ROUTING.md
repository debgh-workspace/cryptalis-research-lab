The original fixed run_baseline.ENV omits bytecode suppression; root -B alone is not inherited. It verifies the returned ENV, main function-global ENV and shared run_baseline.ENV are the same object, then invokes unchanged main() once. The original wrapper .py is loaded as script source, never imported as a module through a potentially stale wrapper .pyc. It does not read inherited environment values, change role probes, replace the fixed environment, add a site hook, wrap subprocess, or select pytest directly. Existing wrapper, corpus helper, run_baseline, progress plugin, runner and all source221 files stay byte-identical.

Readiness, package-origin and test-runner all receive that ENV.
