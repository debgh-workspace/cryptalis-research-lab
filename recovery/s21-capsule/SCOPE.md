# S21 local recovery capsule

This capsule preserves the exact 210-file S21 source candidate, its produced wheel and source archives, allowlisted RED/GREEN/full-source/installed-focused evidence, reviewed versioned packaging and installation preparations, terminal receipts/reviews, past-evidence audits, and remote composite/artifact verification receipts available at this snapshot.

It excludes the separate NamedExpr follow-up. It does not replace or modify earlier checkpoints. The capsule is LOCAL ONLY and has not been uploaded.

The full regression cells ran against source; installed verification is the recorded focused 253-case matrix, not a full installed-suite claim. Seven historical legacy failures and all seven independent qualification gates remain open/UNKNOWN. Source and artifact identity are not retrospective bytecode attestation or production qualification.

## External inputs and limits

EXTERNAL_RECORDED_PINS.json records 3,339 absolute input paths from preserved hash manifests. These include the exact Python and uv executables, pre-existing S20 environments and dependency/cache contents, baseline source, and auxiliary preparation inputs. Their recorded hashes are retained; their contents are NOT included and were NOT freshly read/verified for this capsule. Multiple recorded hashes, if present, preserve historical versions rather than resolving them silently.

No copied virtual environments, installed dependency trees, toolchains, or cache directories are packaged. The 210-file source includes uv.lock. The known original locked distribution archive gap and installed pycparser/iniconfig provenance mismatch remain open. An offline dependency reinstall or clean-machine build cannot be claimed from this capsule.

Database service/configuration, roles, credentials, live providers, authorized host policy/pins and operating-system runtime state are not included. Restoring files does not recreate an authorized PostgreSQL test environment or approve execution. Any subsequent tests must use the required role-preflight and serialized runner, with applicable approval boundaries.

SENSITIVE_PATTERN_REVIEW.json records explicit path checks and a bounded scan for private-key headers, credential-bearing URLs, AWS key IDs and selected provider-token patterns. Both source text and decompressed wheel/sdist members were scanned. Zero matches is not a universal secret-free proof.

The final restoration verification checks this capsule's actual members for unique relative safe paths, regular-file type, no links/devices, exact inventory, every extracted file hash/size and all 210 source hashes. It does not assert that arbitrary tar archives or every third-party extraction tool are safe. No restored code was imported or executed.
